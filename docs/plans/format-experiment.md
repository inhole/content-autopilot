# 형식 실험과 성과 기반 학습

2026-11-05에 승인한 스펙이다. 결정 내용은 [decisions.md](../decisions.md) 16에 있다. 실험이 끝나 형식을 고정하면 이 문서는 지운다.

## 배경

- 10-19 이후 v2 연결 글 10건의 조회 중앙값은 약 3, 그 전 단독 글은 약 40이었다. 연결 글과 반말 문체(v2)가 같은 시기에 들어와서 원인을 가를 수 없었다.
- 연결 글의 답글 수는 11건 모두 내가 단 답글 수와 같았다(다른 사람 답글 0).
- 조회수는 발행 하루 안에 거의 최종값이 된다.

## 범위

- 포함: 형식 교대(`THREAD_CHAIN_MODE`), 답글 수 보정, 주간 리포트의 형식 비교(28일, 발행 1일 뒤 조회 중앙값), 문체 학습의 "반응 좋았던 첫 줄", 주제 선정의 최근 주제 조회수, 테스트와 문서
- 제외: 인프라·환경변수·재배포, DB 마이그레이션, 대시보드 화면, 주제 점수 분포, 영상 성과, 문체 실험

## 수용 기준과 검증

| # | 기준 | 검증 |
|---|---|---|
| 1 | `THREAD_CHAIN_MODE`가 비어 있고 `THREAD_CHAIN_ENABLED=true`면 `alternate`. 명시값이 이기고, 잘못된 값은 시작 때 오류 | 단위 `test/chain-mode.test.ts` |
| 2 | `alternate`에서 짝수 id 주제는 연결 글, 홀수 id는 단독 글 프롬프트. 재생성도 같은 형식 | 통합 `test/integration/generate-chain.test.ts` |
| 3 | `on`·`off`는 기존 true·false와 같은 동작 | 단위 `chainFor` |
| 4 | 답글 수에서 발행된 내 답글을 뺀다(실패한 조각은 빼지 않음) | 통합 `test/integration/insights.test.ts` |
| 5 | 형식 비교는 news·v2·발행 1일 뒤 조회가 있는 글만, 형식별 건수와 중앙값. 한쪽이 없으면 "비교 불가". 발행 없는 주에도 비교는 보인다 | 단위 `test/insights.test.ts`, 통합 |
| 6 | 같은 형식의 측정된 글이 6건 미만이면 "반응 좋았던 첫 줄"이 없다. 6건 이상이면 중앙값을 넘는 상위 3개 | 단위 `test/style.test.ts`, 통합 `test/integration/style.test.ts` |
| 7 | 연결 글을 쓸 때는 연결 글 성과만, 단독 글은 단독 글 성과만 쓴다 | 통합 `test/integration/style.test.ts` |
| 8 | 최근 주제 중 성숙한 조회가 있는 것만 `· 조회 N`이 붙는다 | 단위 `test/rank.test.ts` |
| 9 | 회귀 없음 | `npm test`, `npm run test:integration`, `typecheck`, `lint` |
| 10 | 운영 데이터로 리포트의 형식 비교가 기준대로 나온다 | 수동: `railway run npm run cli -- report` (읽기 전용) |
| 11 | 운영 데이터로 형식별 "반응 좋았던 첫 줄"과 주제 선정 목록이 나온다 | 수동: 읽기 전용 스크립트 |

## 판단

워커를 다시 띄우면 실험이 시작된다. 형식별로 10건 이상 쌓이면(하루 3건이면 2~3주) 주간 리포트의 `▸ 연결 글 vs 단독 글`을 보고 `THREAD_CHAIN_MODE`를 `on`이나 `off`로 고정한다. v2 단독 글도 조회가 낮으면 형식이 아니라 문체가 원인이니 문체 실험을 따로 계획한다.
